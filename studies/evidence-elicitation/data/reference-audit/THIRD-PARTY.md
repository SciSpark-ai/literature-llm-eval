# Third-party data in this folder

| Files | Source | Licence | What is included |
|---|---|---|---|
| `clef/` , `clef-topic-catalog.json`, `clef-tree.json` | CLEF eHealth Technology-Assisted Reviews in Empirical Medicine, https://github.com/CLEF-TAR/tar, at the commit recorded in `../../data_manifest/clinical-reference-audit.json` | MIT; the licence text is in `clef/LICENSE-CLEF-TAR` | Topic files (review title, objective, Boolean query) and relevance labels by PubMed ID for the 2019 intervention reviews. The collection itself holds no abstracts: it lists PubMed IDs. |
| `synergy-datasets.toml`, `synergy-tree.json` | SYNERGY, https://github.com/asreview/synergy-dataset, at the commit recorded in the same manifest | CC0 1.0 | The dataset index only. |

Licences were read from the source repositories on 2026-10-11. The topics come from systematic reviews
published by Cochrane; the licence above is the one the task organisers attached to their collection.

Please cite the task overview when using the labels: Kanoulas, Li, Azzopardi and Spijker, "CLEF 2019
Technology Assisted Reviews in Empirical Medicine Overview", CLEF 2019 Working Notes.
